# src: React UI

The UI renders `AppState` pushed from Rust (`"state"` event) and calls typed Tauri commands. All view logic (needs-you, grouping, sorting, ages, names) is pure TypeScript in `lib/`, and it's unit-tested.

## Layout

| Path | Owns |
|---|---|
| `lib/bindings/` | ts-rs generated types. Never edit by hand. |
| `lib/ipc.ts` | the only place that calls `invoke`/`listen`: `onState`, `onSettings`, `onFocusRow`, `invokeTyped`, `copyText(text)` (the one clipboard write in the UI, through the Tauri clipboard plugin, since WebKit refuses `navigator.clipboard` outside a gesture it accepts; the main window's capability grants `clipboard-manager:allow-write-text` only), and the `CommandName` union |
| `lib/useSync.ts` | `useStateSync` / `useSettingsSync`: every window (main, popover, Settings) keeps its own store current |

## Rules

- **Windows get only the commands they invoke.** Each window (main, popover, Settings) has its own capability file in `src-tauri/capabilities/` granting exactly the app commands its code calls. A new `invokeTyped` (or `invoke`) call reachable from a window needs that window's grant, plus the command in `generate_handler!` and `build.rs` `COMMANDS`; `scripts/capabilities.test.ts` fails on a missing or extra grant.
- **`useNow` lives in `lib/useNow.ts` on purpose.** It used to sit in `lib/uiHelpers.ts`, which imports `saveSettings`; keeping it in its own file keeps the popover's import graph free of `set_settings`, which the popover window is not granted.
- **Identity:** a row key is always `${machineId}::${paneId}`. herdr ids repeat across machines; never key by pane id alone.
- **Status is never color-only.** Every status shows its text label too: "Needs input", "Done, unseen", "Working", "Idle", "Unknown", "Shell".
- **Colors and sizes come from `tokens.css` variables.** No hex literals in components.
- **Home tab and the hidden screens.** `App` mounts the current Home screen (Dashboard, AllAgents or Workbox) inside `Workspace`, and it stays mounted, hidden, under a terminal tab. So anything that polls or reads herdr from it must also stop while `useHomeVisible()` is false: the Inspector's preview and the Workbox pane-tail reads (`usePaneTails`) pause, and the Dashboard's command-log read stops. The Dashboard makes no herdr calls; it reads `state`, `settings`, the terminal store and `get_command_log` (every 5 s, only while visible and the window is shown). Closing the active terminal tab makes Home active.
- **The one URL:** the app opens `https://herdr.dev` (Onboarding) through `plugin-opener`; the main window's capability allows that URL and no other. No other link, fetch or `<a href>` to the web.
- **Keys typed in `.terminal-panel` belong to the terminal.** The list shortcuts and every other key handler skip an event whose target is inside it (`isInTerminal` in `lib/uiHelpers.ts`); only the native menu's accelerators act there. The list's own keys (arrows, Backspace/Delete, ⌘↩) also act only while the Home tab is active and shows All agents, so a key pressed on the tab strip, the context bar or `document.body` over a terminal never selects, opens or closes a row in the hidden list. The terminal never takes focus while a sheet or dialog is open.
- **Links in a terminal are copy-only.** ⌘-click copies the URL and shows "Link copied"; xterm's web-links addon never opens one. The copy goes through `copyText` like every clipboard write (never `navigator.clipboard`); a refused write shows the error toast "Couldn’t copy to the clipboard.", never "Link copied". No terminal text becomes a command: `term_write` carries only keystrokes and pastes.
- **Fonts:** Geist and Geist Mono are bundled under `fonts/`. No network font loading, and no network calls at all.
- **Accessibility:**
  - real `<button>`, `<a>` and `<input>`/`<label>`, with a visible focus ring;
  - `aria-label` on icon-only buttons;
  - destructive actions always go through `ConfirmDialog`, which renders on the body (so it stays visible when a terminal tab hides the Home slot it was opened from).
- **Copy:** monospace for ids, paths, commands and terminal output; sans for everything else.
- **CLI transparency:** show the exact command for an action where the design does (command box, new-session preview). The text comes from Rust (`previewNewSession`, `copyAttachCommand`, `previewReconnect`), never rebuilt in TS.
- **Unknown inputs:**
  - agent names may be `null`, so use `displayName`;
  - ages may be `null`, so render nothing rather than guessing.

## Testing

- **Vitest + React Testing Library.** Mock `lib/ipc.ts`, not Tauri internals.
- **Fixtures** mirror `src-tauri/tests/fixtures/*.json` (import them directly) with generic names only.
- **Before committing:** `pnpm lint && pnpm typecheck && pnpm test`.
