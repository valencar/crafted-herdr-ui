# v0.2 In-App Terminal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Attach herdr panes in terminal tabs inside the main window (VS Code-style panel), keep "Open in {Terminal}", and add ⌘K palette, ⌘J next-needs-you, tab shortcuts, split view and a native app menu.

**Architecture:**
- **Rust:** runs the existing v1 attach argv on a pty per tab (`TermSessions`) and streams decoded text to the webview over a `tauri::ipc::Channel`.
- **UI:** renders each tab with xterm.js.
- **Shortcuts:** a native macOS menu owns the app shortcuts and forwards them as `"menu"` events, so they work while a terminal has focus.

**Tech Stack:**
- Tauri 2, Rust (portable-pty 0.9, tokio), React 19 / TypeScript 6, zustand 5, vitest + RTL.
- New dependencies:
  - `@xterm/xterm` 6.0.0 and the addons fit 0.11.0, search 0.16.0, webgl 0.19.0, web-links 0.12.0;
  - `tauri-plugin-window-state` 2.x.

**Spec:** `docs/superpowers/specs/2026-10-17-v0.2-in-app-terminal-design.md` (addendum), on top of `docs/superpowers/specs/2026-10-16-crafted-herdr-ui-design.md` (v1).

**Branch:** `feat/v0.2`, off `main` @ 1a1736f.

## Global Constraints

Everything in the v1 plan's Global Constraints and the repo `CLAUDE.md` Hard rules still applies. In particular:
- no personal data;
- run `scripts/check-no-personal-data.sh` before every commit;
- only the public herdr CLI;
- no `--takeover` without the user's explicit answer;
- every status shows a text label.

Added for v0.2:
- **Tabs run only server-built commands.** A terminal tab only ever runs the argv that Rust builds with `open_argv` (pane attach or full UI). The UI never sends a command line; `term_write` carries only keystrokes and pastes.
- **Closing never kills herdr panes.** Closing a tab, quitting or crashing must never end a herdr pane or agent. `term_close` kills only the attach client.
- **Exact versions:** xterm packages are pinned without a range (`"6.0.0"`, not `"^6.0.0"`), bundled by Vite, and never loaded from a CDN. The CSP in `tauri.conf.json` doesn't change.
- **One URL:** the app opens no URL except `https://herdr.dev`. Terminal links are copy-only: ⌘-click copies the link and shows the toast "Link copied".
- **Copy:**
  - "Open here", "Open in {Terminal}", "Detached", "Reattach", "Close tab";
  - "Close a terminal tab first (16 open).";
  - "herdr is still starting. Try again in a moment.";
  - "Nobody needs you right now.";
  - "That terminal is no longer open.";
  - the Activity note "opened in Crafted Herdr".
- **Tokens:** colours come from `tokens.css` only. The 16 ANSI colours are new tokens `--ansi-0` … `--ansi-15`, with dark values.
- **Commands are typed:** new Tauri commands are added to `generate_handler!`, to `CommandResults`/`CommandArgs` in `src/lib/ipc.ts`, and to the snake_case-name / camelCase-args convention.
- **No GUI by implementers:** implementers never open GUI windows. Each GUI-only check becomes a `- [ ]` line under `## v0.2` in `docs/qa-checklist.md`.
- **Checks before each commit:**
  - UI: `pnpm lint && pnpm typecheck && pnpm test`
  - Rust: `cargo fmt --check && cargo clippy --all-targets -- -D warnings && cargo test`, with `PATH="$HOME/.cargo/bin:$PATH"`.

## Review Focus

1. **Keys typed in a terminal never reach Home's list shortcuts.** The worst case is Backspace opening "Close session"; others are arrows moving the selection and ⌘↩ opening a row. *Test owner: Task 6.*
2. **An output burst** (an agent redraw, a 1 MB `cat`) stays bounded. Rust coalesces reads into messages of at most 64 KiB, and the concatenated text equals the input. *Test owner: Task 2.*
3. **A multibyte character split across reads** never becomes U+FFFD. Invalid bytes still do. *Test owner: Task 2.*
4. **The attach ending on its own** (herdr's detach key, an ssh drop, a takeover elsewhere) turns the tab into "Detached" with Reattach. A later `term_write` or `term_close` on it is harmless. *Test owner: Tasks 2 and 5.*
5. **Opening before herdr is located, or a pane that vanished,** produces a sentence in the tab's error state with Retry, never a blank terminal. Menu events that arrive while a sheet or dialog is open are ignored. *Test owners: Tasks 3, 5 and 4.*

### Task 2: Terminal sessions (Rust, no Tauri types)

**Files:**
- Create: `src-tauri/src/terminal/session.rs`
- Modify: `src-tauri/src/terminal/mod.rs` (`pub mod session;`)

**Interfaces:**
- Consumes: `crate::pty::{PtySpawner, TermSize, SpawnedPty}` (Task 1).
- Produces:
  ```rust
  #[derive(Clone, Debug, PartialEq, Serialize, TS)]
  #[serde(tag = "kind", rename_all = "camelCase")]
  #[ts(export, export_to = "../../src/lib/bindings/")]
  pub enum TermEvent { Data { data: String }, Exit { code: Option<i32> } }
  pub type TermId = u32;
  pub type TermSink = Arc<dyn Fn(TermEvent) -> bool + Send + Sync>; // false = receiver gone
  pub const MAX_SESSIONS: usize = 16;
  pub const MAX_CHUNK: usize = 64 * 1024;
  pub struct TermSessions { /* spawner, Mutex<HashMap<TermId, Session>>, AtomicU32 next id from 1 */ }
  impl TermSessions {
      pub fn new(spawner: Arc<dyn PtySpawner>) -> Self;
      pub fn open(&self, argv: &[String], env: &[(String, String)], size: TermSize, sink: TermSink) -> Result<TermId, String>;
      pub fn write(&self, id: TermId, data: &str) -> Result<(), String>;
      pub fn resize(&self, id: TermId, size: TermSize) -> Result<(), String>;
      pub fn close(&self, id: TermId);   // kills the attach client; idempotent; unknown id is a no-op
      pub fn close_all(&self);
      pub fn len(&self) -> usize;
  }
  pub fn decode_utf8(pending: &mut Vec<u8>, chunk: &[u8]) -> String;
  pub fn term_env(base: &[(String, String)]) -> Vec<(String, String)>;
  ```
- Behaviour:
  - **`open`:**
    - With `MAX_SESSIONS` open, it returns `Err("Close a terminal tab first (16 open).")`.
    - Otherwise it spawns with `term_env(env)` and starts one forwarding thread.
  - **The forwarding thread:**
    - blocks on `output.recv()`;
    - drains `try_recv()` into the same buffer until it reaches `MAX_CHUNK`;
    - decodes with `decode_utf8`, and calls `sink(Data)` when the text isn't empty;
    - on disconnect, sends `sink(Exit{code: Some(control.wait())})` and removes the session;
    - if `sink` returns `false`, kills the child and removes the session.
  - **`write` / `resize` on an unknown or ended id** return `Err("That terminal is no longer open.")`.
  - **`term_env`** sets or replaces `TERM=xterm-256color` and `COLORTERM=truecolor` and keeps everything else.
- **`decode_utf8` algorithm:**
  - Append `chunk` to `pending` and loop on `std::str::from_utf8(&pending[start..])`.
  - On `Ok`, take everything.
  - On `Err(e)`, take `valid_up_to()` bytes:
    - If `e.error_len()` is `Some(n)`, push U+FFFD, skip `n` bytes and continue.
    - If it is `None` (an incomplete sequence at the end), keep the rest in `pending` and stop.

### Task 5: xterm tab view and session hook

**Files:**
- Modify: `package.json` (pinned xterm packages), `src/styles/tokens.css` (`--ansi-0`…`--ansi-15`)
- Create: `src/terminal/terminalStore.ts`, `src/terminal/useTermSession.ts`, `src/terminal/TerminalView.tsx`, `src/terminal/xtermTheme.ts`, plus tests `src/terminal/terminalStore.test.ts` and `src/terminal/TerminalView.test.tsx`

**Interfaces:**
- Consumes: `openTerm`, `invokeTyped("term_write"|"term_resize"|"term_close")` (Task 3), and `TermEvent`/`TermTarget` bindings.
- Produces:
  ```ts
  export type TabState = "opening" | "live" | "detached" | "error";
  export type TermTab = { tabKey: string; target: TermTarget; title: string; machineLabel: string; state: TabState; error: string | null; termId: number | null };
  // tabKey: row key `${machineId}::${paneId}` for panes, `full::${machineId}` for full UI
  export const useTerminalStore: UseBoundStore<…> with state
    { tabs: TermTab[]; activeKey: string | null; panelOpen: boolean }
    and actions
    { openTab(t: { tabKey: string; target: TermTarget; title: string; machineLabel: string }): void  // focuses an existing tab with that key; else appends; opens the panel; activates it
      updateTab(tabKey: string, patch: Partial<TermTab>): void
      closeTab(tabKey: string): void            // removes; activates the right neighbour, else left; closes the panel when none left
      activate(tabKey: string): void
      activateIndex(i: number): void            // 0-based; out of range = no-op
      cycle(dir: 1 | -1): void                  // wraps
      setPanelOpen(open: boolean): void; togglePanel(): void }
  export function TerminalView(props: { tab: TermTab; active: boolean; fontSize: number }): JSX.Element
  export function xtermTheme(styles: CSSStyleDeclaration): ITheme  // reads --bg, --text, --focus, --ansi-0..15
  ```
- `TerminalView` behaviour:
  - **Creation:** one `Terminal({ fontFamily: var(--font-mono), fontSize, scrollback: 10000, theme, allowProposedApi: false, macOptionIsMeta: false })` per tab, created once and disposed on unmount.
  - **Addons:**
    - fit;
    - search (exposed through a ref for Task 6);
    - web-links, whose handler copies the URL with `navigator.clipboard.writeText` and calls `showToast("Link copied", "info")`;
    - webgl, inside a try/catch, disposed on `onContextLoss`.
  - **Opening:** on mount it calls `openTerm(tab.target, cols, rows, onEvent)`:
    - `data` → `term.write`;
    - `exit` → `updateTab(key, {state: "detached", termId: null})`;
    - success → `state: "live"`;
    - error → `state: "error"`, `error: actionErrorMessage(e)`.
  - **Input:** `term.onData(d => termId && invokeTyped("term_write", {id, data: d}))`. A failed write is ignored once the tab isn't live.
  - **Size:** a `ResizeObserver` runs `fit()` and then `term_resize`, debounced to 50 ms, and only while `active`.
  - **Keys:** `attachCustomKeyEventHandler(e => !e.metaKey)`, so ⌘ shortcuts stay with the menu and browser.
  - **Detached state:** an overlay reads "Detached" with the buttons "Reattach" (Enter) and "Close tab".
    - Reattach calls `openTerm` again into the same xterm.
    - Close calls `closeTab`.
  - **Error state:** the message with "Retry" and "Close tab".
  - **Unmount:** calls `term_close` if `termId` is set.
