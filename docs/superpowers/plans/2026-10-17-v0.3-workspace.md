# v0.3 Dashboard Home and Tabbed Workspace Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace v0.2's bottom/right terminal panel with a tabbed workspace in the middle of the window. A pinned Home tab (Dashboard / All agents / Workbox) comes first, then terminal tabs grouped by workbox. A new Dashboard home and a single "Open" split button come with it.

**Architecture:**
- **App shell:** `App.tsx` owns the window chrome once: Header, Sidebar, sheets and toast.
- **Workspace:** `terminal/Workspace.tsx` replaces `TerminalPanel.tsx`. It holds a tab strip, a Home slot that hosts the current home view, and the terminal stack under a `.terminal-panel` element.
- **Terminal store:** gains a Home-tab model (`activeKey` is `"home"` or a tab key), the last terminal tab, folded groups, and strip-order navigation.
- **Pure helpers:** tab grouping and Dashboard metrics live in pure helpers. Metrics use only data the app already has, plus the in-memory command log.

**Tech Stack:** Tauri 2 (Rust, ts-rs bindings), React 19 + TypeScript, zustand, xterm 6, vitest + React Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-17-v0.3-workspace-design.md`. It extends the v0.2 addendum and the v1 spec. Code map (scratch, gitignored): `.superpowers/sdd/v0.3-digest.md`.

## Global Constraints

- **No personal data.** Use the generic examples only: machines `buildbox`, `gpubox`, `staging`; projects `api-service`, `web-app`, `infra`. Run `scripts/check-no-personal-data.sh` before every commit.
- **Colours:** no hex literals in components. Every colour is a `tokens.css` variable (`src/styles/styles.test.ts` guards this). Dark only.
- **No new herdr calls.**
  - The Dashboard reads only `state`, `settings`, the terminal store, and `get_command_log`.
  - It reads `get_command_log` (the in-memory log) once every 5 s, each read scheduled 5 s after the previous one ends.
  - It reads only while it is visible and `document.hidden` is false.
- **Status is never colour-only.** Every dot has its words in visible text, a tooltip, or an accessible name.
- **Terminal views are never unmounted** when switching tabs or views; unmounting ends the session.
  - The terminal stack, its context bar and the find bar stay inside an element with class `terminal-panel`, so `isInTerminal` keeps working.
- **Keys typed in the terminal belong to the terminal.**
  - Home's list shortcuts (arrows, Backspace/Delete, ⌘↩) run only while the Home tab is active and showing All agents.
  - ⌘N and ⌘R keep working while the Home tab is active and focus isn't in the terminal.
- **Exact copy** (do not reword):
  - `Dashboard`, `All agents`, `Needs you`, `Open`, `Go to tab`, `Open here`, `Open in {Terminal}`, `Open full herdr UI`, `Copy attach command`, `Copied`
  - `Detach`, `Close pane…`, `All tabs`, `Nobody needs you right now.`, `Finished, not looked at yet`, `Right now`, `Working now`
  - `Blocked the longest`, `Workboxes online`, `herdr response`, `Terminal tabs`, `Open herdr`, `Retry now`, `Dashboard Beside Terminal`, `Open a session to start a terminal.`
- **Terminal tabs:** the cap of 16 stays in Rust (`MAX_SESSIONS`); v0.2 error text is unchanged.
- **Dependencies:** no new ones. The existing pins stay exact.
- **Each task ends green:** `pnpm lint && pnpm typecheck && pnpm test`, and for Rust changes `cd src-tauri && cargo test && cargo clippy --all-targets -- -D warnings && cargo fmt --check`. Test output has no warnings.
- **Commits:** Conventional Commits, on branch `feat/v0.3`. Never push.

## Review Focus

1. **Hidden list shortcuts:** with focus on the tab strip, the context bar or `document.body` while a terminal tab is active, Backspace/arrows/⌘↩ must not select, open or "Close…" a row in the hidden Home list.
2. **Closing tabs:** closing the active tab (×, ⌘W, Detach, or the overlay's "Close tab") makes Home active. Closing the last tab leaves no dangling `activeKey`. ⌘W on Home does nothing.
3. **Folded groups:** a needs-input tab inside a folded group, reached by ⌘J, a notification, the sidebar, ⌘2–⌘9 or ⌃Tab, unfolds its group and becomes active and visible.
4. **Command-log polling:** it stops when the Dashboard is hidden (terminal tab active, or another home view), unmounted, or the window is hidden. No overlapping reads and no timer left after unmount.
5. **Machines without a fresh snapshot:** a workbox that is reconnecting, needs attention, is disabled, or has `snapshot: null` renders its card, tiles and tab group without throwing. Stale data is marked "as of {age} ago".
