# v0.4 Two-Row Workspace Tabs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Orchestration:** as in `CLAUDE.md` § Build orchestration. Ledger, briefs and reports go in `.superpowers/sdd/2026-10-19-v0.4-tab-rows/` (gitignored). Branch: `feat/v0.4-tab-rows` (already created, holds the spec commit).

**Goal:** Replace the one-row tab strip with two rows: a workbox row (Home plus one Chrome-style tab per workbox) over a session row (the active workbox's tabs as large two-line tabs), and make terminal-link copying work on WebKit.

**Architecture:**
- **Clipboard:** every copy goes through one `copyText` in `lib/ipc.ts`, backed by Tauri's clipboard-manager plugin (write-text only), replacing `navigator.clipboard.writeText`.
- **Store:** `terminalStore` loses folding and gains a per-workbox "last tab" memory plus `activateMachine`.
- **UI:** `TabStrip` becomes a composer over `WorkboxRow`, `SessionRow` and `HomeViewsRow`. `tabOrder` stays as it is, so ⌘2–⌘9 and ⌃Tab don't change.

**Tech Stack:** Tauri 2 (Rust), React 19 + TypeScript, zustand, vitest + React Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-19-v0.4-tab-rows-design.md` (spec §N below). It extends the v0.3, v0.2 and v1 specs.

## Global Constraints

- **No personal data.** Use the generic examples only: machines `buildbox`, `gpubox`, `staging`; projects `api-service`, `web-app`, `infra`; homes `/home/dev`, `/Users/dev`. Run `scripts/check-no-personal-data.sh` before every commit.
- **Colours:** no hex literals in components or in the new CSS rules. Every colour is a `tokens.css` variable. Dark only.
- **Status is never colour-only.** Every dot and badge has its words in visible text or in an accessible name.
- **Status words** are `tabStatus`'s, verbatim: "Working", "Idle", "Needs input", "Done, unseen", "Unknown", "Shell", "Opening…", "Detached", "Error", combined as "Detached · Needs input".
- **Terminal views are never unmounted** by switching workbox or Home view. They stay inside `.terminal-panel`.
- **Links stay copy-only.** ⌘-click copies; nothing opens a URL but herdr.dev.
- **Clipboard capability:** `clipboard-manager:allow-write-text` only, on the main window only. No read permission anywhere.
- **Clipboard copy:** a failed copy shows the error toast "Couldn’t copy to the clipboard." (curly apostrophe, as `CommandBox` has it today).
- **Tests mock `lib/ipc.ts`**, never Tauri internals or the plugin module (except `ipc.ts`'s own test).
- Commit messages: Conventional Commits, ending with the `Co-Authored-By` line from the session.

## Review Focus

1. **A tab whose workbox has left the machine list (a stray group).** Its workbox tab still shows (label from `tab.machineLabel`, health "Unknown") and clicking it works. Test: Task 3 `workbox_row_shows_a_stray_workbox_with_unknown_health`.
2. **The remembered tab of a workbox gets closed, then the workbox tab is clicked.** It activates the workbox's first remaining tab, never a stale key and never Home. Test: Task 2 `activate_machine_falls_back_when_the_remembered_tab_closed`.
3. **The same tab title on two workboxes** (`planner` on `buildbox` and `gpubox`). The session row shows only the active workbox's one, and a click activates the right key. Test: Task 3 `session_row_shows_only_its_workbox_even_with_equal_titles`.
4. **⌘2–⌘9 numbering while the session row shows only one workbox.** Tooltips still use the flat strip order across workboxes, not the position in the row. Test: Task 3 `session_tab_tooltip_uses_the_flat_shortcut`.
5. **The clipboard refuses the write.** An error toast "Couldn’t copy to the clipboard.", and never a "Link copied" / "Copied" toast. Test: Task 1 `a_refused_copy_shows_the_error_toast` at each of the three call sites.
